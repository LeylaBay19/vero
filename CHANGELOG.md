# Версии ВЕРО

## v1.2.0 — доступ гендиректора и подписи дорожек · 04.11.2026

Исправлено безусловное требование приглашения для существующей организации. Проверяются сохранённые подключения; гендиректор без связи подтверждает полномочия УКЭП без создания дубля. При обычном входе без УКЭП сохраняется подтверждённая роль; для подписи МЧД УКЭП обязательна. В BPMN названия ролей вынесены в левую колонку, исправлен излом стрелки после ошибки подписи.

## v1.1.0 — единое подключение сотрудника · 04.11.2026

Приглашение на личную/корпоративную почту → вход через mos.ru без повторного ИНН → принятие → автоматическая МЧД руководителю, если выбраны полномочия. Почты могут отличаться. Обычный доступ не зависит от ожидания подписи; сотрудник МЧД не подписывает. Обновлены интерфейс, BPMN с тремя дорожками и описания. Реальные интеграции имитируются стендом.

## v1.0.0 — предыдущий вариант

Снимок перед переходом на единый процесс подключения сотрудника (04.11.2026).
Приглашение с email/паролем; выдача МЧД отдельным процессом.
Сохранены исходники, готовый интерфейс и четыре схемы в BPMN/SVG/PNG,
включая подробные схемы регистрации, подготовленные в этом чате.

Версии фиксируются Git-тегами. Каждый тег содержит интерфейс и схемы вместе.
