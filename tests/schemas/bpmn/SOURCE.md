# BPMN 2.0 XML Schema

Unmodified public OMG schema files downloaded 2026-11-04 from:
https://www.omg.org/spec/BPMN/20100501/BPMN20.xsd

Dependencies in the same official directory: Semantic.xsd, BPMNDI.xsd, DC.xsd, DI.xsd.
Retained locally for reproducible offline validation; original copyright notices preserved.
Run `python scripts/validate_bpmn.py` with lxml installed.
