# История переписки — описание исходного экспорта

Это нормализованный экспорт видимой переписки чата «Описать регистрацию ЛК юрлица на mos.ru» для продолжения работы над ВЕРО. Подробности снимка и количество сообщений — [manifest.json](manifest.json).

- [conversation.md](conversation.md) — удобно читать в GitHub и передавать Codex частями.
- [conversation.html](conversation.html) — открыть локально в браузере вместе с папкой assets.
- [conversation.json](conversation.json) — структурированные сообщения пользователя и ассистента.
- assets/ — доступные изображения из пользовательских сообщений.

Экспорт включает видимые промежуточные сообщения. Служебные инструкции, рассуждения и вывод инструментов в него не входят. Повторные технические представления одного сообщения объединены. Ранние решения и ответы могут быть отменены более поздними; актуальный контекст — [RESUME.md](../RESUME.md) и [PRODUCT.md](../docs/PRODUCT.md).

Это не формат импорта нативной сессии Codex. Копирование history/ не создаёт этот же чат в боковой панели. Ссылки в исторических сообщениях могут вести на локальные файлы исходного компьютера; исходные PDF, ZIP и Word не копировались автоматически.

Снимок 05.11.2026 обновлён: 555 видимых сообщений и 116 уникальных изображений из исходного чата и прежней перенесённой ветки. Экспорт scripts/update_chat_snapshot.py сохраняет прежние сообщения и добавляет доступные новые, исключает служебные данные. Последние замечания к линиям ожидают отдельного разрешения.
