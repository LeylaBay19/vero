# Контекст текущего проекта

Цель: описать сложный продукт при разрозненной документации для заказчика в Markdown. Нужны карта продукта, сценарии, правила, сущности/статусы, права, открытые вопросы, карта экспертов, проект RACI, функциональные и нефункциональные требования.

Охватывай текущее положение и планы с явным разделением статусов. Решения по противоречиям и новым правилам сообщает пользователь. По умолчанию работа документная; кодовый пакет доступен для отдельной задачи.

В текущем проекте есть источники в `skud-analysis/sources` и прежний разбор `skud-analysis/04-consolidated.md`. Наличие пути в профиле не означает, что материал доступен или уже изучен. Прежний отчёт — навигация, а не независимый первичный источник; при продолжении сохраняй имеющиеся ID и проверяй выводы по оригиналам.

В прежнем отчёте отмечено, что часть материалов описывает целевое поведение, реализация не исследовалась и некоторые макеты отсутствовали. Это сведения отчёта, требующие проверки актуальности, не доказательство текущего поведения. Автоматический приоритет источников не установлен; конфликт решает пользователь.

Исходные пользовательские описания ролей хранятся в корне текущего проекта для истории и уточнений. Они не нужны для переноса универсальной библиотеки; изменение исходного текста не обновляет исполняемые профили само по себе.

## Расширенный документный маршрут
Для задачи сведения макетов, совещаний, аналитических документов и нормативных оснований выбран product-documentation-synthesis. Важны многочисленные ветвления, явные совпадения/расхождения, бизнес-требования, процессы, сценарии, FR/NFR, глоссарий, UX и схемы. Конкретный нормативный акт и Figma-ссылка ещё не назначены в задаче настройки; не считай автоматически прежний документ из папки тем актом, который пользователь имеет в виду.

## Согласованность сот

По поручению пользователя от 2026-10-30 платформа состоит из множества сот (услуг) с собственными продуктологами. Цель: единая логика повторяющихся задач, выявление и доведение расхождений UX/логики до исправления, единая документация и управляемое обновление. Используй platform-consistency для межсотовых задач. Реестр сот, общие паттерны и утверждённая всей командой RACI ещё не предоставлены; не выдумывай их утверждение. Решения сообщает пользователь. Фоновый исполнитель и подключения для автообновления этим обновлением библиотеки не создаются.
