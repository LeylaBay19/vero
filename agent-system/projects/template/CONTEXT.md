# Контекст нового проекта

Это начальный контекст. Установи предмет задачи, аудиторию, границы, доступные источники и критерии результата по поручению пользователя. Не переноси сведения другого продукта из библиотеки проектов.

Решения сообщает пользователь. Неизвестные владельцы, правила, версии и числовые цели остаются неизвестными. Проектные источники и результаты указываются относительно корня целевого проекта.

## Для платформы из услуг

При выборе platform-consistency установи перечень сот/услуг и их владельцев, общие и сквозные процессы, библиотеку паттернов и версии, статус согласования RACI и исключений. Неизвестные сведения сохраняй вопросами. Укажи источники и реальную готовность автоматизации: доступы, событие/расписание, исполнитель, политика публикации, проверки и история. Шаблон ничего не включает автоматически.
