# Согласованная платформа

Подключаемый пакет для множества сот (услуг) с собственными продуктологами. Объединяет исследование, библиотеку продуктовых паттернов, UX, нормативные основания, RACI, исключения и контроль обновлений. Полный маршрут и поля записей: [WORKFLOW.md](WORKFLOW.md).

## Установка и запуск

Из корня проекта сначала получи план, затем добавь `--apply`:

```powershell
python .\agent-system\adapters\codex\deploy.py --target . --pack product-documentation --pack software-development --pack product-documentation-synthesis --pack platform-consistency --default-pack platform-consistency --project template
```

Так сохраняются все 13 ролей и 48 навыков. Отдельно пакет platform-consistency устанавливает 11 документных ролей; Design и Implementation подключаются пакетом разработки. Адаптер не запускает работу и не устанавливает мониторинг.

Можно писать своими словами. Пример:

```text
Используй platform-consistency и отдельных субагентов.
Соты и процессы: [список]. Источники: [конкретные материалы и версии].
Сравни повторяющиеся задачи, логику и UX. Подготовь общие паттерны,
матрицу применимости, расхождения, проект RACI и единый комплект документации.
Различай одинаковые условия, допустимые параметры и исключения.
Решения сообщаю я. Фактические отличия сохраняй до подтверждённого исправления.
Проведи независимое Review и Verification. Результаты: [каталог].
```

## Обновление по источнику

```text
В источнике [ID] появилась версия [версия]. Сравни её с [предыдущая версия].
По platform-consistency определи затронутые правила, паттерны, соты и документы.
Подготовь изменения и проверки. Сохрани ручные правки и историю.
Покажи решения, необходимые по RACI, и непроверенную актуальность.
```

## Что означает автообновление

В библиотеке реализован порядок работы агентов, а не фоновый исполнитель. Нужны назначенные источники, доступы, событие/расписание, среда запуска, политика публикации и журнал ошибок. До их настройки автоматизация имеет статус «не настроено». Изменения могут автоматически готовиться, но новый бизнес-смысл не утверждается моделью. Фактические сроки обновления и показатели качества задаются командой, не выводятся из установки пакета.

Начни с 2–3 сот и одного сквозного процесса. Проверь сравнение условий, путь решения до исправления и одно изменение источника. В [tests/fixture.md](tests/fixture.md) есть искусственные материалы для проверки поведения навыков; это не документация реального продукта.
