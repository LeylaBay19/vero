# Искусственные материалы для проверки пакета

Все организации, соты и записи ниже вымышлены. Это не нормативный акт и не свидетельства работающего продукта.

PAT-01 v1, утверждённое решение DEC-01 тестового владельца платформы: автор неоплаченной заявки в статусе «Черновик» может удалить её после подтверждения; результат — заявка удалена. Применимость только к этому сочетанию условий. В платных заявках последствия отдельно не определены.

Сота A, Figma-экспорт A v1, экран 10: автор неоплаченной заявки «Черновик» видит подтверждение удаления. Наблюдений реализации нет.

Сота B, Figma-экспорт B v3, экран 14: автор неоплаченной заявки «Черновик» удаляет её без подтверждения. Документ B v4 §2 уже переписан на PAT-01 v1. Обновлённого макета или работающего продукта не предоставлено. Продуктолог B написал «наверное, можно закрыть».

Сота C, описание C v2 §5: автор оплаченной заявки в статусе «Исполняется» подаёт запрос на отмену с расчётом возврата. Источник правил возврата отсутствует.

EXC-01: разрешение тестового владельца платформы для B на PAT-01 v1, действовало до 2026-09-30; дата проверки 2026-10-30, нового решения нет.

RACI v0 — проект, согласование не предоставлено. В строке изменения PAT-01 одновременно два A. Эксперт B предложил PAT-01 v2 без подтверждения, но полномочия на платформенные решения не установлены. Пользователь ещё не передал новое решение.

Событие E1: источник A обновлён с v1 на v2. Новые локаторы недоступны. E2 дублирует E1. Автор вручную добавил пояснение к разделу A после последнего сохранённого снимка. Политика автопубликации не утверждена; действующий исполнитель обновлений не назначен.
