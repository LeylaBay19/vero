# Пакет synthesis

Этот пакет собирает сложный продукт из макетов, совещаний, документации и нормативных оснований. Основной читательский результат — PRODUCT.md с индексом, схемами/приложениями и явными расхождениями. Источники процесса исследования сохраняются отдельно.

Методология: [product-documentation-methodology](../../skills/product-documentation-methodology/SKILL.md). Контракт команды — [pack.json](pack.json), порядок — [WORKFLOW.md](WORKFLOW.md).

Для установки только документного расширения из корня проекта:

```powershell
python .\agent-system\adapters\codex\deploy.py --target . --pack product-documentation-synthesis --project template --apply
```

Пакет подключает десять профилей; библиотека дополнительно сохраняет технические Design и Implementation в software-development. Для доступа ко всем ролям выбери также software-development и, при необходимости, базовый product-documentation. Количество установленных профилей не означает одновременный запуск всех ролей.

Постановка:

```text
Используй product-documentation-synthesis и субагентов.
Область: [процесс]. Источники: [список]. Результаты: [каталог].
Подготовь единый PRODUCT.md со всеми разделами пакета.
Сохраняй локаторы, версии, различие фактов/планов/решений,
совпадения, расхождения и неизвестное.
Проверь ветвления, выполни Testing документации,
независимый Review и Verification исходных критериев.
Решения сообщаю я. Код продукта и макеты не меняй.
```

До реального запуска нужны конкретные материалы/доступы. Установка модуля не означает, что закон, записи встреч или макеты уже изучены. Новые UX-решения не создаются автоматически, спорная применимость нормы передаётся на компетентное рассмотрение.
