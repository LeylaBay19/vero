# Искусственные источники для проверки навыков

Это вымышленный тест, не материалы какого-либо реального продукта и не нормативный акт. Файлы, Figma и закон из примера физически не предоставлены; ниже полный доступный набор сведений. Локаторы заданы внутри этого текста.

## SRC-A — описание макета, версия 2, экран E1
Роль — автор заявки. Заявка отправлена, проверка ещё не началась. В этом состоянии поле суммы недоступно для редактирования, кнопка редактирования неактивна. Это сведения об описанном макете, не наблюдение production. Дата неизвестна.

## SRC-B — аналитический документ, версия 2, пункт 3
«Автор заявки может менять сумму после отправки до начала проверки. После начала проверки изменение суммы запрещено». Статус утверждения и дата неизвестны.

## SRC-C — совещание, пункт заметок 7
Спикер Анна: «Предлагаю, чтобы проверяющий тоже мог менять сумму, но это ещё надо обсудить». Других решений или полномочий участников в заметках не указано. Дата неизвестна.

## SRC-D — памятка, версия 2, пункт 1
Дословно повторяет SRC-B пункт 3 и прямо ссылается на него как на первоисточник. Самостоятельная проверка поведения не проводилась.

## SRC-E — вымышленный нормативный фрагмент, пункт X
Для этого теста придумана фраза «оператор сохраняет дату изменения статуса». Официального акта, юрисдикции, редакции, условий применимости и подтверждения правового статуса не предоставлено. Это не действующий закон.

## SRC-F — запись требования качества, пункт 4
«Сохранение должно выполняться быстро». Показатель, порог, область сохранения, нагрузка, условия измерения и статус утверждения неизвестны.

## SRC-G — пользовательское решение для теста, пункт 1
«Для версии 2 утверждаю поведение автора по SRC-B пункт 3. Макет SRC-A надо привести в соответствие, но новые макеты сейчас не создаём. Права проверяющего пока не определены». Это решение относится к вымышленному заданию и не является решением о реальном продукте.

## Назначение публикации
Нужен понятный заказчику черновик одного сценария с требованиями, терминологией, UX и видимыми вопросами. Исходники менять нельзя. Отсутствующие определения начала проверки, правил других ролей, ошибок и NFR уточняются, а не достраиваются.
