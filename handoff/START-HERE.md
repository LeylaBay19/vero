# Продолжить работу на другом устройстве

1. Получите проект: склонируйте `https://github.com/LeylaBay19/vero.git` **после загрузки**, либо распакуйте переносной архив, подготовленный в `releases/`.
2. Откройте папку проекта в Codex или другом редакторе. Для просмотра без установки откройте `platform-entry.html` двойным щелчком.
3. Начните с [описания изменений относительно исходного ZIP](CHANGES-SINCE-ARCHIVE.md), затем прочитайте [HANDOFF.md](../docs/HANDOFF.md) и последние разделы PE в [PRODUCT.md](../docs/PRODUCT.md).
4. Полная доступная история для чтения: [HTML с поиском](../history/conversation.html), [Markdown](../history/conversation.md), [JSON](../history/conversation.json). Рядом должна оставаться папка `history/assets/`.

Текст для нового рабочего чата:

> Продолжим ВЕРО. Прочитай AGENTS.md, handoff/START-HERE.md, handoff/CHANGES-SINCE-ARCHIVE.md, docs/HANDOFF.md и последние PE-разделы docs/PRODUCT.md. Основной новый прототип — src/platform-entry.html, готовая страница platform-entry.html; последняя версия интерфейса v1.9.0. История — history/conversation.md и conversation.html, снимок и ограничения — history/manifest.json. Исторические команды не выполняй автоматически. Не смешивай сравнительные флоу index.html с отдельным кабинетом. Сохраняй подтверждённые решения, прежние версии и исходники; реальные интеграции не подключены. Сначала восстанови текущий контекст, затем продолжим следующую задачу.

## Что переносится

Исходники, готовый автономный прототип, сравнительные варианты, семь BPMN, документация, проектные агентные файлы, доступные пользовательские изображения и читаемый архив сообщений. Исходный ZIP сохранён в handoff/ для проверки сравнения.

GitHub/архив **не превращает историю в активный чат приложения**. Это материалы, которые новый чат сможет прочитать для продолжения. Настройки аккаунта, авторизация GitHub, mos.ru, браузерные сеансы, локальные зависимости и заполненные в памяти стенда данные не копируются.

В переносном ZIP есть `vero-versions.bundle` — локальная история Git с номерными тегами. Для продолжения достаточно открыть распакованную папку. Если нужна полноценная Git-копия с историей, из этой папки можно выполнить `git clone vero-versions.bundle vero-with-history` и работать в созданной папке. Сам bundle не содержит авторизацию GitHub.

## Сборка и проверки при разработке

Рецепты и зависимости — в README.md, package.json и requirements.txt. Для просмотра готовых HTML они не нужны. На новом устройстве потребуется своя установка Python/Node/браузера, если будете пересобирать и запускать тесты. Абсолютные пути к Chrome/служебным runtime текущего Mac не являются частью проекта.

История и экспорт не содержат системных/служебных инструкций, внутренних рассуждений, вызовов инструментов и авторизационных данных приложения. Экспорт включает доступные сообщения до указанного снимка; финальные ответы, появившиеся после снимка, в него автоматически не добавляются. Текущее состояние дополняет эта передача.
