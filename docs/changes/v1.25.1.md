# Стенд регистрации v1.25.1

Во вкладке «Варианты» два сценария: «Письмо → пароль» и «По ТЗ». Вкладка «Сравнение регистрации» возвращает три сценария исходного стенда: Тринити через mos.ru, Тринити через ЭП и Орбита. Во вкладке «Схемы» восемь процессов двух активных вариантов в вертикальной и горизонтальной раскладках.

Архив v1.25.0 сохраняет сборку с UX-вариантом и его схемами. В отдельной странице `registration-ux.html` убрана кнопка проверки просроченной ссылки, а выбор сертификата открывается по кнопке «Подключить через УКЭП» после создания аккаунта.

Для переноса распакуйте `deliverables/vero-registration-stand-v1.25.1.zip` и откройте `prototype.html`. В комплекте обе архивные сборки, отдельная страница схем и по 16 файлов BPMN и SVG.
