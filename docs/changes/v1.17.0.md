# v1.17.0 — история тестирования и удаление схем

По поручениям пользователя от 05.11.2026:

- В общей панели появились «← Назад» и «Вперёд →» с номером посещённого шага. Это инструменты тестирования прототипа, отдельные от продуктовых форм.
- Сохраняются состояние модели, поля, пароли, согласия, выбранные значения, раскрытые блоки и прокрутка. История работает в вариантах 1 и 4, архивных 2/3 и сравнительных флоу; разные варианты сохраняют собственную историю.
- «Вперёд» возвращает только к уже посещённому следующему шагу и не отправляет формы. Новый маршрут после отката обрезает прежнюю ветку вперёд. «Начать заново» очищает историю выбранного сценария. До первого перехода обе кнопки отключены.
- Восстановление возвращает согласованное состояние аккаунтов и проверок, а не только нарисованный экран. Перепроверены регистрация/письмо/пароль, окно и разрешения mos.ru, подключение компании, ролевой ЛК и подтверждение вывода в варианте по ТЗ. Статусы и демонстрационные операции при перемещении не выполняются повторно.
- Снимки хранятся только в памяти iframe, максимум 80 шагов на сценарий, не включаются в экспорт HTML и не отправляются родителю. Внешняя панель получает только доступность стрелок и счётчик. Реальные интеграции и сервер не добавлены. Выбранный файл в системном file-input повторно не подставляется: браузер ограничивает программное восстановление такого выбора.
- Все текущие схемы удалены из стенда, нового автономного HTML и текущей публикации. Во вкладке и прежних адресах схем пустое состояние, ссылок скачивания нет. Старые опубликованные SVG/PNG/BPMN исключены из нового Site-артефакта. Исторические исходники и старые номерные версии Git сохранены. Обычная сборка больше не создаёт прежние схемы автоматически.
- Правила будущих схем — docs/DIAGRAM_RULES.md: разнести тексты, по возможности избежать стрелок, при пересечении прервать линию под текстом; переносимые подписи остаются однозначно связанными с элементом.

Новый тест prototype-history проверяет откат и повторное движение через регистрацию, ветвление, диалоги mos.ru и финансового подтверждения, сохранение полей/согласий, сброс и независимость вариантов, мобильные размеры, отсутствие сети. Обновлены проверки схем и автономной поставки. Sandbox/CSP сохранены.
