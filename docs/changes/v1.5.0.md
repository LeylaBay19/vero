# v1.5.0 — UI по рабочему прототипу ВЕРО

Поручение: перенести оформление с трёх пользовательских скриншотов. До работ сохранён тег v1.4.2. Использованы только изображения как визуальные источники; на admin.vero.ru не выполнялись вход, запросы или изменения. Полный email из референса не внесён в репозиторий.

Исходник: src/platform-entry.html. Результат: platform-entry.html, web/platform-entry.html, deliverables/vero-platform-entry-v1.5.0.html. Новый синий/белый каркас, контурный SVG-логотип, боковое меню и аккаунт внизу, строка раздела сверху. Каталог из трёх сервисов и подключения продукта с поиском. Организация — секции реквизитов с редактированием контактов; сотрудники — таблица и модальное приглашение. Мобильная адаптация. SVG иллюстрации и логотип воссозданы самостоятельно, не оригинальные assets.

Права и бизнес-границы: руководитель управляет сотрудниками и контактами, сотрудник не получает это право от оформления. Ведомство сохраняет просмотр. «Рабочие пространства» — каталог по референсу, не вернувшийся промежуточный выбор. Обязательные телефон/СНИЛС из скриншота не перенесены в минимальное приглашение без отдельного решения; поля ФИО/email оформлены по образцу. Все процессы остаются демонстрационными; карточки не выдают право действий в сервисах.

Независимый review: review_v2 (профиль gpt-6.1-sol/medium, расход не предоставлен), отчёт v1.5.0-review.md. Исправлены зависимость типа ЮЛ/ИП от последнего ИНН и перенос уведомления приглашения между компаниями. Контакты, приглашения и уведомления теперь по ID организации. Модальный Escape/закрытие возвращают фокус кнопке; автозаполнение доступно внутри native dialog.
