# v1.3.0 — отдельный предлагаемый вариант 2

Поручение: добавить предложенный многосервисный процесс отдельным вариантом под номером 2. Предыдущая версия v1.2.0 сохранена существующим Git-тегом; старые флоу остаются доступны.

Вариант 2 отделяет личный аккаунт от подтверждения организации и требований соты ОССиГ. Добавлены код email, альтернативный mos.ru, приглашение с подтверждением получателя, личные черновики, подготовка организации, проверка полномочий и отложенная МЧД для сервиса. Ошибки и отсутствие УКЭП не блокируют общий кабинет. Все интеграции демонстрационные.

Схемы: три новых процесса в BPMN 2.0 с DI, SVG и PNG, отдельная автономная страница schemes-v2.html. Старые схемы остаются на schemes.html.

Проверки и ограничения фиксируются в docs/HANDOFF.md. GitHub назначен пользователем: LeylaBay19/vero. Авторизация Git пока отсутствует; push предыдущих версий завершился `could not read Username`. Новую версию сохраняем локально, не утверждаем, что она опубликована.
