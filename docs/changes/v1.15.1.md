По правкам пользователя от 05.11.2026 с общего стенда удалён вариант 1. Остались варианты 2–5 с прежними номерами; выбранным при открытии остаётся 2. Предыдущий интерфейс сохранён тегом v1.15.0 и его автономными HTML. Исторический исходник первого входа в отдельном platform-entry.html не удалён; в основном стенде он недоступен.

В варианте 4 первый вход по email теперь проходит шаги: email → код из письма → «Задайте пароль» → личный кабинет. Почта показана как недоступный для редактирования логин; пользователь вводит пароль и его повтор. Пустой пароль, только пробелы, длина меньше 8 символов и несовпадение не открывают кабинет. Ввод сохраняется при ошибке, есть кнопки показа пароля и общее демо-заполнение. Аккаунт в этом сценарии активируется после корректного сохранения пароля. Если пароль для этой почты уже задан в текущем сеансе, повторный код не требует задать его заново.

По приглашению после подтверждения почты тоже задаётся пароль, затем показывается принятие приглашения. mos.ru без подтверждения почты кодом сохраняет прежний отдельный маршрут. Данные и проверки локальные, отправка писем и серверная авторизация не подключены.

Обновлены прототип, подпись варианта 4 («Код → пароль»), описание шага аккаунта, BPMN/SVG/PNG процесса v2-account и переносные файлы. Схема сохраняет отдельные действия пользователя и платформы. Все 7 BPMN прошли XSD и структурные проверки; импорт в редактор не проверялся.
