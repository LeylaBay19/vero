# ВЕРО · отдельный UX-вариант регистрации

Версия v1.24.0-ux.1 от 06.11.2026. Самостоятельный HTML открывается из `registration-ux.html`. Базовая версия общего стенда зафиксирована тегом `v1.24.0`.

- Руководитель подтверждает email и задаёт пароль либо входит через демонстрационный Mos ID. После создания аккаунта он переходит к выбору УКЭП, проверке реквизитов и отправке заявки. Контактные поля и недостающие сведения можно заполнить до отправки. Повторный вход открывает статус отправленной заявки.
- Сотрудник использует один адрес из приглашения. При существующем аккаунте он входит, иначе задаёт пароль для нового аккаунта на этом адресе. Принятие приглашения показано отдельным действием после входа. Просроченная или отозванная ссылка оставляет возможность обычного входа.
- Повторная отправка письма доступна с текущего шага. При входе в существующий аккаунт email сохраняется. В случае совпадения email при входе через Mos ID пользователь подтверждает привязку паролем существующего аккаунта.
- Вариант посвящён регистрации руководителя и сотрудника. Права в сервисах и канал уведомлений по заявке отложены до уточнения. Авторизация, письма, сертификаты и решения платформы работают на демонстрационных данных в памяти страницы.

Сборка — `python3 scripts/build_registration_ux.py`. Проверка — `node tests/registration-ux.cjs` с установленным Playwright. Проверены оба маршрута регистрации, повторная отправка и восстановление, отказ и одобрение заявки, привязка Mos ID, выход из недействительного приглашения, ширины 320, 390 и 1280 px. Тест проверяет iframe sandbox и отсутствие внешних запросов.
