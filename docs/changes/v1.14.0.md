# v1.14.0 — пять вариантов входа в одном ряду

Решение пользователя от 05.11.2026: сохранить три вкладки «Вход», «Сравнение регистрации», «Схемы»; убрать промежуточный выбор текущего/предлагаемых процессов. Во «Входе» один ряд «Вариант 1»–«Вариант 5».

| Вариант | Содержимое |
| --- | --- |
| 1 | Первый текущий сценарий регистрации |
| 2 | Mos ID и привязка аккаунта |
| 3 | Прежний «Предлагаемый вариант» |
| 4 | Прежний «Предлагаемый вариант 2» |
| 5 | Отдельный процесс по UX/UI ТЗ, 39 экранов ЛК и кошелька |

UI приведён к простому оформлению предлагаемого варианта: нейтральный фон, тёмные основные кнопки, обычные поля и рамки. Сценарии и правила разных вариантов остаются раздельными. Встроенный переключатель 1/2 скрыт только в общем стенде; самостоятельный HTML сохраняет его.

Вариант 5 встроен в тот же экран с sandbox allow-scripts и исходной CSP. Отдельная ссылка на ЛК со сводкой сохранена. Все макеты остаются автономными, без реальной регистрации, mos.ru, банка или ЭП.
