# Стенд регистрации v1.25.0 · 06.11.2026

Основной вход в стенд — `prototype.html`. Вкладка «Варианты» показывает три самостоятельных прототипа.

1. С UX-правками. Регистрация руководителя, сотрудника по приглашению и работа с существующим аккаунтом. Просроченное и отозванное приглашения скрыты в меню демонстрации.
2. Письмо → пароль. Исходный вариант 1 из v1.24.0.
3. По ТЗ. Регистрация, кабинет и кошелёк из исходного варианта по ТЗ.

Вкладка «Схемы» содержит 13 процессов. Пять относятся к UX-варианту, шесть к исходному варианту 1 и две к регистрации по ТЗ. Для каждой схемы доступны вертикальная и горизонтальная раскладки, масштабирование, разворачивание с выходом по Esc, BPMN и SVG. Схемы показывают этапы регистрации, входа и подключения. Действия в кабинете и операции кошелька выходят за их границы.

Ссылка «Архив · v1.24.0» открывает точную копию предыдущей сборки вместе с её вкладками, сравнением и сценариями. Исходные данные архива хранятся в `archive/prototype-v1.24.0.html`.

Сборка выполняется командой `python3 scripts/build_stand.py`. Для передачи распакуйте `deliverables/vero-registration-stand-v1.25.0.zip` и откройте `prototype.html`. В ZIP также входят архив, автономная страница схем и 26 файлов каждого формата BPMN и SVG.
