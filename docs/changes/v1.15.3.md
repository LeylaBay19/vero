# v1.15.3 — следующий шаг после Mos ID

По двум отметкам пользователя от 05.11.2026 в варианте 1:

- В карточке «Что даёт Mos ID» пункты «Ещё один способ входа» и «Вход без ввода пароля ВЕРО» занимают отдельные строки.
- После успешной привязки Mos ID у пользователя без организации сразу появляется предложение подключить организацию. Кнопка «Подключить организацию» открывает существующий поиск по ИНН; «Сделать позже» ведёт к сервисам. Кнопка «Перейти в профиль» удалена с этого экрана.
- Для уже подключённого сотрудника/руководителя повторное подключение компании не предлагается, кнопка ведёт к сервисам. Профиль и его настройки по-прежнему доступны через меню аккаунта.

Подключение Mos ID не выдаёт членство, роль или права: поиск ИНН и проверка полномочий проходят прежним отдельным процессом. Письма, mos.ru и проверки остаются локальной демонстрацией. Sandbox/CSP не менялись.

Пройдены registration-mos-id (включая перенос строк по фактическим координатам, переход к ИНН, откладывание, отсутствие новой организации и админ-прав, существующее членство), registration-revisions и stand-routing. В остальных флоу поведение не менялось.
