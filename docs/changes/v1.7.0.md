# v1.7.0 — организации, данные и проверка платформой

## Coordination

Пакет software-development с ограниченной проверкой platform-consistency. Основание: 4 аннотации пользователя и просьба об этапе проверки/отправки после УКЭП. База v1.6.0, коммит 3727ee5, тег неизменён. Аудит законодательства не выполняется: новые правила редактирования — предложение UX, не правовое заключение. Полного переноса Figma нет.

Критерии: понятный диалог контактов; юридические сведения нельзя изменить прямо в нём, есть путь поддержки; текстовый выход; два сравнимых варианта нескольких компаний/ролей, явно компания+роль в сервисе и отсутствие переноса прав; пробное название раздела; УКЭП → проверка данных → подтверждение → отправка → ожидание/одобрение/отказ, без director-контекста до одобрения; предыдущее поведение сравнений сохраняется; локальная автономность и адаптивность.

Автор координатор: src/platform-entry.html, tests/platform-entry.cjs и docs. Текущие модель/токены основного чата инструментом не измеряются. Независимый reviewer /root/review_v2 назначается отдельно по локальному обязательному workflow, не является автором. Модель существующего исполнителя из предыдущего профиля gpt-6.1-sol medium, нового переключения не выполнялось. Область записи reviewer — только v1.7.0-review.md.
