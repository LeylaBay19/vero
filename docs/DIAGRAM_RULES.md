# Правила оформления будущих схем

Основание: три комментария пользователя от 05.11.2026. Применять ко всем новым и перерабатываемым схемам.

1. Тексты не накладываются друг на друга. Подписи можно переносить и перемещать; должно оставаться понятно, к какому элементу или переходу они относятся.
2. По возможности размещать подписи вне стрелок и других линий. При переносе использовать близкое расположение либо явную привязку к элементу.
3. Если текст всё же пересекает стрелку, линия под текстом прерывается с небольшим просветом вокруг букв. Линия не проходит поверх или сквозь надпись.
4. Проверять общий вид и увеличенный масштаб, включая длинные и многострочные подписи, вопросы у развилок и подписи исходов.

По последующему решению пользователя все текущие схемы удалены из действующего стенда и нового HTML. Эти правила сохранены для будущей работы; готовые схемы в текущей версии отсутствуют. Исторические исходники в Git не являются действующими схемами.
