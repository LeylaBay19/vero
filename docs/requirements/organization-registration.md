# PRD · Регистрация организации в ВЕРО

**Статус:** черновик для обсуждения с дизайном и разработкой.

## Задача пользователя

Как генеральный директор, я хочу подключить организацию к своему аккаунту ВЕРО, чтобы работать от её имени и управлять доступом сотрудников.

Сценарий начинается после входа в личный аккаунт. Регистрация аккаунта и принятие приглашения сотрудником описываются отдельно.

## Основной сценарий

| Шаг | Действие пользователя | Поведение системы |
| --- | --- | --- |
| 1 | Начинает подключение организации. | Предлагает выбрать сертификат УКЭП. |
| 2 | Выбирает сертификат. | Проверяет срок действия и полномочия генерального директора. При успехе показывает данные организации и владельца сертификата для сверки. |
| 3 | Подтверждает данные и отправляет заявку. | Принимает заявку и показывает статус. |
| 4 | Получает результат. | При одобрении связывает аккаунт с организацией и выдаёт права администратора этой организации. |

## Правила и критерии приёмки

| ID | Условие | Ожидаемый результат |
| --- | --- | --- |
| ORG-01 | Срок сертификата истёк. | Видна причина. Можно вернуться к выбору и с действующим сертификатом перейти к сверке данных. |
| ORG-02 | Полномочия генерального директора не подтверждены. | Подключение останавливается, видна причина, права не выдаются. Доступ сотрудника оформляется по приглашению. |
| ORG-03 | Организация уже есть в ВЕРО, связь с аккаунтом отсутствует. | После одобрения аккаунт связан с существующей организацией. Дубликат не создаётся. |
| ORG-04 | Заявка на проверке или отклонена. | Права администратора не выдаются. При отказе видна причина. |

## Решение интерфейса текущей итерации

При просроченном сертификате показываем всплывающее окно «Проблема с сертификатом» с действием «Выбрать другой сертификат». Ветка 08б убрана. Пользователь должен понимать, чьи данные сверяет, каков статус заявки и что можно сделать дальше.

## Открытые вопросы

1. Как повторить проверку, если сервис УКЭП временно недоступен?
2. Как узнать результат проверки после выхода из ВЕРО?
3. Какие данные можно исправить при расхождении и как подать заявку повторно?
